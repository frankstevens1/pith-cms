# Support

Use GitHub issues for reproducible bugs and documentation corrections. Use repository discussions,
when enabled, for setup and design questions. Pith provides no guaranteed individual support or
hosting service.

Bug reports should include Pith package versions, Next.js/React/Node.js versions, adapter and
publishing mode, deployment environment, a minimal reproduction, and redacted error output. Never
include credentials, repository URLs that must remain private, session data, or content that cannot
be shared.
